照片和封面图都放在这个文件夹里。

========================================================
  ★ 首页大封面（整张图当背景）—— 先看这个
========================================================

把你想要的那张「动漫情侣一起做饭」的图片，
直接放进本文件夹，命名成：

        cover.jpg

（也支持 cover.png / cover.webp / cover.jpeg）

放好之后，不用改任何代码，重启一下服务就生效：

  · 网页版：手机浏览器打开菜单页，顶部整块就是这张图
  · 小程序：首页顶部、关于页顶部、我的页那张卡片，
            都会用这张图当背景
  · 原来那个小图标（🍳）会自动隐藏

图片要求：
  · 横图最好，建议 1200 × 800 以上
  · 建议压在 300KB 以内 —— 微信小程序整个包不能超过 2MB
  · 图上会盖一层很淡的白色渐变（越往下越白），
    这样店名和口号压在图上仍然看得清
  · 想调文字和图片的贴合程度，改
    server\static\style.css 和 pages\index\index.wxss 里的
    .hero-veil 那一块透明度

想换图：直接把 cover.jpg 覆盖成新图，重启即可。
想不用封面：把 cover.jpg 删掉（或改名），重启就回到原来的浅色头部。

========================================================
  下半部分的背景图
========================================================

菜单区域（搜索框、菜品列表那一大块）的背景，用这个文件：

        lower.jpg

（同样支持 lower.png / lower.webp / lower.jpeg）

· 适合用竖图，因为这一块比较高
· 图上会盖一层很淡的白色，保证菜品卡片和文字看得清
· 菜品卡片本身是纯白的，所以背景再花也不影响看菜
· 不想要这块背景，把 lower.jpg 删掉即可

两张图的分工：
        cover.jpg   →  顶部封面（横图或方图更合适）
        lower.jpg   →  下半部分背景（竖图更合适）

========================================================
  怎么给菜加照片
========================================================

推荐做法（不用管文件名）：
  打开店主后台 → 点「＋ 加一道菜」→ 选照片 → 保存。
  照片会自动存到 images\dishes\ 下面，名字就是菜品编号。

如果你想手动放：
  1. 把照片复制到  images\dishes\  这个文件夹里
     建议命名成  1.jpg  2.jpg  100.jpg（数字就是菜品编号）
  2. 打开  项目目录\server\menu.py
     找到那道菜，把 image 改成  "/images/dishes/1.jpg"
     注意：斜杠是正斜杠 /，不是反斜杠 \；开头要有 /images/
  3. 保存后重启服务（黑窗口按 Ctrl+C，再双击 start.bat）

注意事项：
  · 支持 jpg / jpeg / png / webp / gif
  · 建议压在 1MB 以内，不然手机加载慢；
    微信小程序整个包不能超过 2MB，照片太大上传会失败
  · 照片最好是横的或方的，手机上显示比较好看
  · 想用网上的图，image 里直接填 https:// 开头的网址也行
    （小程序用网络图片要去微信公众平台配置 downloadFile 合法域名）
